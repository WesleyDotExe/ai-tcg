# The first seat, measured (engine/src/dev/firstSeatFixes.ts)

Rows are seat rules: "shipped" is the rules the game plays today (rules-2 since session 71: the second seat
starts on 24 health, the first on 20 and skips its first draw); "rules-1" is both on 20, as before session 71.
A row is a `rules` option the instrument passes to runMatch (engine/src/state/types.ts MatchRules).
The second seat is always p2. 50% is a fair seat.
