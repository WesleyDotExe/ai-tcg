AI-TCG — fourth-faction (Null) balance measurement (design principle 3)
Session 8, 2026-09-16. Generated by `npm run balance --workspace=engine`
(engine/src/dev/balanceReport.ts), 300 seeds per matchup. Follows the same
method session 7 established for the first three factions (see
progress/balance-report-001.txt) — this is the same measure-then-fix cycle
applied to Null, the fourth faction (progress/roadmap.md item 1), which had
zero balance measurement before this session because it didn't exist yet.

Method: unchanged from balance-report-001.txt — same agent policy on both
sides of each matchup (isolates faction balance from agent skill), first
player alternated by seed (isolates first-player advantage, confirmed small
via the mirror matchups below), a pairing flagged at >=60% win rate for
either side, double-flagged (both agent policies) treated as strong
dominant-archetype evidence.

=== BEFORE (initial measurement, Null as first designed/shipped this session) ===

AggressiveAgent vs AggressiveAgent:
  Cortex 101-199 Null  (33.7% / 66.3%)  <-- FLAG (favors Null)
  Swarm   81-219 Null  (27.0% / 73.0%)  <-- FLAG (favors Null)
  Aegis   58-242 Null  (19.3% / 80.7%)  <-- FLAG (favors Null)
  (pre-existing Cortex/Swarm/Aegis numbers unchanged from balance-report-001.txt)
  mirrors: Null 49.7% first-player win rate (no first-player-advantage confound)

RandomAgent vs RandomAgent:
  Cortex  65-235 Null  (21.7% / 78.3%)  <-- FLAG (favors Null)
  Swarm   25-275 Null  ( 8.3% / 91.7%)  <-- FLAG (favors Null)
  Aegis   47-253 Null  (15.7% / 84.3%)  <-- FLAG (favors Null)
  mirrors: Null 49.0% first-player win rate

Cross-check (flagged under BOTH policies): Cortex vs Null, Swarm vs Null,
AND Aegis vs Null — all three cross-faction matchups against Null,
under both a greedy heuristic and uniform-random play. This is an even
stronger signal than session 7's Cortex dominance (which was 2 of 2
matchups): Null beat every other faction, every time it was measured.

Root-cause reading of the Null card pool (engine/src/data/nullCards.ts):
Unlike session 7's Cortex fix (two specific outlier cards), this reads as
a genuine density/breadth problem, not one or two bad numbers — of Null's
14 unique cards, the large majority contribute a strong non-vanilla effect
(3x Segfault Handler removal, 3x Fork Bomb AOE, 3x Corrupted Process
evolve-damage, 2x Kernel Panic unconditional destroy, 2x Deprecated
Routine permanent decay, plus efficient survivability tools) with almost
no low-impact filler slots the way Cortex/Swarm/Aegis each have several
(e.g. Fail-safe Unit, Diagnostic Loop, Barrier Drone). Three specific
numbers stood out as outliers against that reasoning, versus the curve
precedent the other three factions had already established:
  1. Fork Bomb (NL-005): 2 damage to ALL enemy units at cost 2, telegraph
     1 — the same cost/telegraph as Aegis's Perimeter Turret (3 damage,
     ONE random target) and Cortex's Dormant Exploit (a single Stasis),
     but hitting every enemy unit instead of one. Especially devastating
     against Swarm's wide, low-toughness board (many 1-health units) —
     Swarm vs Null was the single worst matchup (73.0%/91.7%).
  2. Null Shell (NL-007): +0/+4 for cost 1, versus the established
     precedent for a flat-health Tool at that cost (Aegis's Plating
     Module and Swarm's Chitin Plating are both +0/+3 for cost 1) — a
     clear, unreasoned stat outlier once compared side by side.
  3. Propagating Exploit (NL-008): a 2/2 for cost 2 that permanently
     gains +1/+0 every time it attacks, uncapped, for the rest of the
     game — no other card in any faction has unbounded permanent growth
     with no built-in check, and at a 2-mana cost it comes down early
     enough to compound for many turns before most decks can find an
     answer.

=== FIX APPLIED ===

Three targeted, minimal changes to engine/src/data/nullCards.ts (no card
removed, no mechanic changed — the same kind of stats/cost tuning pass
session 7's fix was):
  1. Fork Bomb: AOE damage 2 -> 1. Keeps the "hits everyone" identity that
     makes it distinct from the other factions' single-target telegraph
     payoffs, but roughly halves its early-game board-wipe power against
     wide, low-toughness boards.
  2. Null Shell: healthBonus 4 -> 3, matching the +0/+3-for-1-cost
     precedent Aegis's Plating Module and Swarm's Chitin Plating already
     established rather than quietly beating it.
  3. Propagating Exploit: cost 2 -> 3. Keeps the permanent-growth identity
     (Null's own distinct mechanic, not shared with any other faction)
     but delays when it starts compounding by a turn, giving the
     opponent more time to develop an answer before it's threatening.

Cross-check (flagged under BOTH policies): Aegis vs Null only. Cortex vs
Null and Swarm vs Null both dropped out of the double-flag (Cortex:
66.3%/78.3% -> 54.7%/66.7%; Swarm: 73.0%/91.7% -> 59.7%/87.3%) — real,
measured improvement from the fix, in the same direction under both agent
policies. Aegis vs Null did not meaningfully move (80.7%/84.3% ->
75.0%/81.3%) since none of the three changed cards involved Aegis-specific
interactions.

=== Honest read: what this does and doesn't prove ===

- This is a partial fix, not a claim that Null is now balanced. Aegis vs
  Null remains double-flagged and the single worst number in either
  measurement (75-81% for Null) — worse than any pairing session 7 left
  open. A plausible (not yet verified) explanation: Aegis's whole identity
  is stacking value into a small number of evolved/tooled-up units
  (Warden, Prime Aegis), and Null's headline new mechanic is exactly
  "unconditional single-target removal" (Kernel Panic's destroy) plus
  global stat decay (Segmentation Fault, Null Singularity, Deprecated
  Routine) — this may be closer to a genuine hard counter than the
  "strong soft counter" design principle 3 asks for, and is worth
  revisiting specifically (not just re-running the same three-card fix)
  in a future balance session.
- Under RandomAgent specifically, Null still beats both Cortex and Swarm
  at a meaningfully-above-50% rate (66.7%, 87.3%) even though neither is
  double-flagged anymore (both dropped under the Aggressive policy). This
  is the same category of "real, partial progress, not a claim of
  balance" session 7 documented for its own leftover single flags — named
  here rather than left implicit.
- Both dummy agents are unsophisticated (no lookahead, fixed heuristics);
  a real agent might play around Null's removal differently than either
  policy does here (e.g. by not overcommitting into open AOE), so these
  numbers describe dummy-agent play, not skilled play.
- Following session 7's own precedent and the owner's approval of it
  (2026-09-15 owner feedback: "stopping after one measure-then-fix cycle
  rather than chasing an exact balance target — approved"), this session
  also stops after one fix cycle rather than iterating further, to keep
  the slice bounded. Aegis vs Null (still double-flagged) and Null's
  above-50%-but-under-60% edge over Cortex/Swarm are both named as open
  debt below, not silently dropped.

Next step this leaves for a future session: a second, more targeted look
specifically at the Aegis-vs-Null matchup (is Kernel Panic's destroy, or
the combined weight of Null's several stat-debuff effects against a
stacking-based faction, the actual driver — the two haven't been isolated
from each other yet), using the same measure-then-fix pattern.
