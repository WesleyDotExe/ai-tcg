  printed amount even when the resolver would deliver nothing. Cortex Engineer's repair resolved

2. THE AGENT FIX (engine/src/agents/lookaheadAgent.ts)
-----------------------------------------------------
Three changes, all "value only what the resolver actually does":
  a. heal: capped at missing health (player: maxHealth - health; unit: damageTaken), after
     subtracting flat heals already pending on the stack for the same target.
  b. gainEnergy: capped at maxEnergy - energy (the resolver's own cap).
  c. a Command whose effect is worth <= 0 also costs the card (a 0-cost Command used to tie
     with passing and be cast on a coin flip; only Burst Credit is 0-cost).
Waste measured directly (200 Cortex-vs-Null games, seeds 1-200):
  before: Cortex Engineer repair resolved 1231 times, healed anything 66 times (100 hp total)
  heal cap only: 314 resolved, 81 healed (stacked second repairs on its own pending one)
  heal cap + pending-stack heals: 93 resolved, 93 healed (141 hp total)
Decomposition on seeds 1-900: the gainEnergy cap alone moves nothing measurable; the heal cap is
all of the shift (Cortex vs Null 58.9 -> 64.9 with the heal cap alone; 65.7 with the stack check).
Change (c) cannot move any pre-slice measurement: no faction card costs 0.
Why this matters beyond Cortex: the owner's 2026-09-29 item 1 asks whether Null's removal cards
are weak or misplayed. This is direct proof the arbiter can misplay a card badly enough to move
an edge by 6 points. That question is still open for Null's removal (not investigated here).

3. NEUTRAL PACKAGE SEARCH
-------------------------
Objective per faction: sum over its three edges of (distance from win rate to the band)^2, x1e4.
Guard: the faction's own mean win rate may not drop more than 0.5 points (no sandbagging).
Ship rule: held-out objective (seeds 901-3400) must beat the shipped deck's.
Protected from cuts: Kernel Panic; Null's Bit Rot, Null Pointer, Watchdog Timer, Decay Ward.

A first run is NOT what shipped, for three reasons, all fixed before the final run:
  - it cut Null copies (Null Pointer first, then Propagating Exploit / Dangling Pointer). The owner's
    2026-09-29 entry rules out further Null removals until note 3 is settled, so Null was re-run
    add-only (36 -> 40, nothing cut);
  - its ablation dropped a copy outright, which breaks the 25% removal cap for Null (9/35), so
    only one Null card was ever a candidate. The ablation now swaps a copy for a vanilla probe;
  - it had no held-out ship rule; its Aegis pick measured worse on held-out seeds.
First-run Null (swap mode, NOT shipped): -1 Dangling Pointer, -2 Propagating Exploit, +3 Commodity
Rack; held-out +5.8 / -0.1 / +3.0.
