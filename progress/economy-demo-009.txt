## 7. What the store and the schema refuse

    a deck holding the Zero-Day card (live since session 42): saved, as it should be
    salvaging the Zero-Day copy (raw SQL): refused (CHECK constraint failed: disposed_reason IS NOT 'salvaged'
           OR (origin = 'pack' AND account_bound = 0 AND finish = 'standard' AND series_kind = 'set'))
    changing a copy's secret code (raw SQL): refused (a copy's card, finish and secret code never change)
    a secret copy with no secret code (raw SQL): refused (CHECK constraint failed: (finish IN ('secret', 'zeroDay')) = (secret_code IS NOT NULL))
    a Glitch copy of a card with no Glitch version: refused ("CX-015" has no Glitch version)
    the card viewer for S0-ZD1: owned 1, salvageable 0, why not: Zero-Day copies are never salvaged
