Owner API demo 005 — the owner's daily pack over HTTP (session 65)
========================================================================
Rule (owner 2026-10-04): one free pack a day that only the owner can claim, stacking up to 2.
The day runs midnight to midnight Sydney (owner 2026-11-01). The database is a real file.

1. Not signed in: both daily-pack endpoints answer 401
------------------------------------------------------------------------
> GET /api/packs/daily  -> 401
  error: not signed in
> POST /api/packs/daily/claim  -> 401
  error: not signed in
