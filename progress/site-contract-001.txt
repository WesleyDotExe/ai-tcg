# The site contract check: the render's site types against the served answers (game sessions 90-91, 94-95)

The website's own client (render/src/site/siteApi.ts, unchanged) called the real owner API over a real
season file with the live ladder playing (5 owners, a fixed clock and seeds). Each answer it parsed was
type-checked as a literal of the type the client declares for that call, with the render workspace's
compiler settings.
  MISMATCH  the answer doesn't fit the type: the site may read something that isn't there.
  UNTYPED   the server sends a field the type doesn't name: harmless; the site could read it.
            (Every one is listed: the check repeats with each reported field taken out.)
