AI-TCG balance report 019 — session 25 (2026-10-01): the agent checks the owner asked for
=========================================================================================

Owner-feedback 2026-10-01 (session 24 decisions), items 1 and 4, in the owner's order:
  1. Commodity Rack: check whether LookaheadAgent under-values card advantage FIRST; nerf the
     card to 3/2 only if it is still over-rate on a correctly-valuing agent; then re-search.
  4. Null card-vs-agent check: are Null's removal/debuff cards (Bit Rot, Null Pointer, Watchdog
     Timer, Decay Ward) weak, or does the agent misplay them?

HEADLINE
  - Card advantage: NOT an agent problem. No card-draw weight beats the shipped 1.5 head to head
    (16,000 games per weight); 4.5 and 6 are measurably WORSE. Draw cards do not improve in the
    probe at weight 4.5. So Commodity Rack was nerfed 3/3 -> 3/2, as the owner sequenced it.
  - Null's cards: one real agent misplay, one smaller one, one weak card.
      Bit Rot   — AGENT MISPLAY. 222 of 240 casts hit a unit that never fought that turn
                  (the -3/-0 wore off unused). Cutting a copy was worth +2.7 pts to Null on the
                  old agent (CI excludes 0); on the fixed agent the cut is -0.5 (CI spans 0).
      Decay Ward — host choice was a coin flip (112/206 casts on a weaker host than available).
                  Fixed: 258/258 now on the best unprotected unit. Its ablation delta barely
                  moved (+1.5 -> +1.4, CI spans 0), so the host was not what made it weak.
      Watchdog Timer — WEAK CARD. Played sensibly (it is cast when nothing better is) but drew
                  only 36 cards in 900 games. Cutting a copy is still +1.9 on the fixed agent
                  (CI 0.3 to 3.4). Not cut: owner-protected mechanic; flagged.
      Null Pointer — situational, not misplayed: always hits the only directive; ended 270 of
                  900 games stranded in hand with no directive to hit. +1.2 to cut (CI spans 0).
  - Two LookaheadAgent fixes shipped (both sides of every measurement use them):
      a. A this-turn buff/debuff is valued by the fight it changes: the pending combat on the
         stack if there is one, else (own turn) how much it improves the best attack involving
         that unit, else 0. Affects Bit Rot, Swarm's Reflex Spike and Rally Cry, Cortex's Hotfix.
      b. A Tool prefers the more valuable host and never re-grants Barrier to a unit that has it.
  - Re-search on the fixed agent with the 3/2 Rack (--strip-neutral, held-out ship rule):
      Null: no neutral card helps; the bare 36 ships (held-out objective 314 -> 249).
      Aegis: -1 Salvage Reflex, +1 Uplink Tower ships (243 -> 234). Per-edge changes are noise.
      Cortex: keeps its package (re-search fails held-out). Swarm: none (already 0 objective).
  - Net ring (Lookahead, 900 seeds): Null is now clearly the weakest faction, 40.0 / 38.9 / 41.4
    vs Cortex / Swarm / Aegis. Three edges OUT, all Null's: Null-vs-Cortex (even band), Aegis
    over Null, and the same Cortex-over-Null edge from Cortex's side. Most of the drop is the Rack
    nerf: Null ran 3 Racks, and the nerf alone moved it about -6 / -3.5 / -6 (decomposition
    below). At 2,500 seeds: 38.3 / 40.4 / 41.6.
