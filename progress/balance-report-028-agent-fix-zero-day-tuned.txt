AI-TCG balance report 028: the reference agent fixed, the ring re-baselined, the 3 Zero-Day cards tuned to the cap (session 41)
Owner 2026-10-18 (answers to session 40): "Question 1: A. Fix the reference agent first: value auras over several turns
and stuns by how long they last, for every card, not only modal ones. Re-record the ring baseline once. Then re-measure

10% of the games where the card is played."

== 1. What changed in LookaheadAgent (engine/src/agents/lookaheadAgent.ts) ==
  - One path for every unit's own abilities (estimateUnitAbilities), plain or modal: statics, onDeath (x0.5, on the board
    as it is now) and turn triggers (x2, the Directive horizon). Before, a plain unit's statics, onDeath and turn
    triggers were worth 0, and modal units took a second path (estimateModeAbilities, now gone). An evolution counts
    what the evolved form adds that the base lacked (e.g. Prime Aegis's auras). onAttack/onDamaged are still not read.
  - Auras (buffAllies) over several turns: size x the average number of units covered over the controller's next 3
    turns, one more unit a turn up to the free slots, turn k weighted 0.75^k. Before: size x units now x 0.5, once.
    Same rule for Directive auras and for auras on the opponent's side.
  - Scaling self-stats (selfStatFromScaling) count the played unit itself and are worth the difference from the printed
    stat (the engine overrides the printed stat). Before: half the scaled total, modal units only.
  - Statuses by kind and duration (statusValue). Stasis: the unit's attack for each of its turns held (1.0 the first,
    x0.8 each later one), minus turns it is already held. Overload: its ticks as damage. Barrier: +1.5 on your unit
    (0 if it already has one). Before: every status 0.6 x attack, any kind, any duration, with a debuff's sign, so a
    Barrier on your own unit scored BELOW passing (a bug: Aegis Warden's evolve and any "your unit gains Barrier").
  - Stasis per turn = 1.0 x attack was chosen over 0.6 by measurement: at 0.6 Kill Switch's Lights Out was still picked
    in 1-4% of casts (1,000-seed probe), at 1.0 in 35-55%, and Kill Switch measured stronger with the agent choosing
    (3.60 vs 2.10 worst edge at 1,000 seeds): the choice reads the board instead of ignoring a mode. On shipped decks
    the two settings are indistinguishable head to head (+1.4 vs +1.8 [both intervals exclude 0], 1,000 seeds).
  Unit tests: engine/test/lookaheadValuation.test.ts (8; 7 of them fail on the session-40 agent, each pick checked
  across 8 agent seeds so a tie can't pass by luck).
